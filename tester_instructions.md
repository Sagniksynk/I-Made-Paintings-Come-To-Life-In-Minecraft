## Keybindings

These keybindings can be used during gameplay. They are found under the `Template Mod General` category in the Controls menu.

| Action | Default Key | Description |
| :--- | :--- | :--- |
| **Activate Painting** | `,` | Sends a signal to wake up/activate the paintings. |
| **Activate Painting (Alt)** | `z` | Sends an alternate activation signal to sixth painting. |
| **Activate Room** | `.` (Period) | Sends a signal to activate the room hand animation. |

## Commands

###  Painting Mob Reset
Use these commands to trigger a reset on the respective painting mobs across all dimensions. This starts a 1-minute cooldown for the mobs.
**Usage:** `/<command>`

* `/deletefirstpaintingmob`
* `/deletesecondpaintingmob`
* `/deletethirdpaintingmob`
* `/deletefourthpaintingmob`
* `/deletesixthpaintingmob`
* `/deleteseventhpaintingmob`
* `/deleteeighthpaintingmob`
* `/deleteninthpaintingmob`
* `/deletetenthpaintingmob`


### Cooldown Management
* `/bypasscooldown` - Clears the cooldown for all painting mobs.
